Midterm Study Guide

Session 9 · in class · covers Sessions 1–8

The midterm is in class and monitored. You write and troubleshoot real R code. You may use your printed notes and homework — no internet, no AI tools. (This is the assessment the AI policy warns you about: if AI has been writing your homework, this is where it shows.)

How it works mechanically: you get an .R script with the questions plus the data files it needs, all distributed together — you answer in the script and submit it. Two things to know in advance:

  • Light data wrangling IS testable. The exam is code-based, so expect to read_csv() a file and use the everyday verbs — filter(), count(), summarize(), mean() of a logical. Nothing from the pivot/join weeks will be tested cold, but getting data into a testable shape is part of doing statistics.
  • No live brm() fit during the exam. The Bayesian ANOVA model comes pre-fit — you load it with readRDS() and do the emmeans interpretation workflow (plot the posterior means, run the pairwise comparisons, read the intervals). Practice fitting models before the exam anyway: the interpretation only makes sense if you’ve run the workflow yourself.

Best preparation: the practice banks for Sessions 2–8 — ungraded problems with hidden solutions, in exactly the exam’s style.

1. Data & measurement

  • Explain the four levels of measurement (nominal, ordinal, interval, ratio)
  • Give examples of each, especially from criminal justice research

2. Descriptive statistics

  • Calculate mean, median, and mode in R
  • Compute variance and standard deviation in R
  • Explain what the standard deviation means in plain language
  • Make and interpret a histogram
  • Explain why an outlier affects the mean more than the median or mode

3. Probability & sampling

  • Simulate random events (e.g., sample(), rbinom())
  • Count outcomes with count() or table()
  • The difference between small and large samples (law of large numbers)
  • Build and interpret a contingency table
  • Calculate and interpret a conditional probability from a table
  • Reverse a conditional with Bayes’ theorem using a counting table: base rate + sensitivity/false-positive rate → P(condition | positive test)

4. Inference & confidence intervals

  • Compute group means
  • Make and interpret a boxplot
  • Run a two-sample t-test with t.test()
  • Interpret a 95% confidence interval (what it means when the CI includes 0 vs. not)

5. Frequentist vs. Bayesian thinking

  • What a p-value means (and doesn’t mean)
  • How Bayesian probability statements differ — P(hypothesis | data)
  • Why priors matter and how ignoring them can mislead
  • The recidivism example: same data, different interpretations
  • Run and interpret a Bayesian t-test with ttestBF()

6. Comparing groups / ANOVA

  • Make a boxplot of groups
  • Run a one-way ANOVA with aov() and interpret the output (at least one group mean differs)
  • Interpret a Bayesian ANOVA using the workflow we practiced (brms + emmeans) — on the exam the model arrives pre-fit (readRDS()); you run emmeans(), plot(), and pairs() on it
  • Interpret pairwise comparisons (posterior interval crossing 0 = no credible difference)

General advice

  • Practice running the R code from your homework, labs, and in-class exercises — the midterm only asks you to do things we’ve already done.
  • Make sure you can both run the code and explain in words what the output means.
  • Focus on big ideas: variability, sampling, inference, and comparing groups.
  • Don’t overthink the Bayesian part — it will be at the same level as what you’ve already done in class and on homework.

R you should know cold

mean(x); median(x)
library(modeest); mfv(x)                  # mode
var(x); sd(x)

# plots (ggplot as practiced in lab; base equivalents also fine)
ggplot(df, aes(x)) + geom_histogram()
ggplot(df, aes(group, y)) + geom_boxplot()

# counting & contingency tables
df |> count(x, y)
table(df$x, df$y)

# inference
t.test(y ~ group, data = df)              # two-sample t-test + CI
library(BayesFactor); ttestBF(...)        # Bayesian t-test

# ANOVA
aov(y ~ group, data = df) |> summary()

# Bayesian ANOVA workflow (exam version: the model is pre-fit)
library(emmeans)
bayes_model <- readRDS("midterm-anova-fit.rds")   # distributed with the exam
bayes_anova <- emmeans(bayes_model, ~ group)
plot(bayes_anova)
pairs(bayes_anova)                         # interval crossing 0 = no difference

# (For practice at home, fitting it yourself looks like:)
library(brms)
bayes_model <- brm(y ~ group, data = df, chains = 2, iter = 2000, seed = 705)

Concepts you should be able to explain

  • Levels of measurement — nominal, ordinal, interval, ratio (with examples)
  • Mean/median/mode — what each tells you; effect of outliers
  • Variance & SD — measure of spread; SD ≈ typical distance from the mean
  • Law of large numbers — small samples fluctuate; large samples stabilize
  • Contingency tables — marginal totals, conditional probability
  • Confidence intervals — CI includes 0 → difference not supported; excludes 0 → supported
  • p-value — probability of data this extreme (or more) if the null is true
  • Bayesian probability — probability of the hypothesis given the data; priors matter — a low base rate can turn a “90% accurate” test into a mostly-wrong one
  • ANOVA — compares variance between groups vs. within groups
  • Bayesian ANOVA — pairwise posterior intervals; crossing 0 = no credible difference
