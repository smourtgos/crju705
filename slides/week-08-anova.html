Experiments and Group Comparisons

Experiments: IVs and DVs

Independent variable (IV): what we change or compare — the groups.

Dependent variable (DV): what we measure — the outcome that (maybe) depends on the IV.

Independent variable Dependent variable
Type of training program Test score
Type of fertilizer Plant height
Region of the country Annual precipitation
Patrol strategy assigned to a beat Response time (minutes)

Why ANOVA?

  • A t-test compares 2 means
  • ANOVA compares 3+ means
  • Use it when the IV is categorical (the groups) and the DV is numeric (the outcome)
  • The name is strange: ANalysis Of VAriance — we’re asking about means, but the test works by comparing variances. That’s the whole trick, and it’s coming up.

Why Not Just Run a Pile of t-Tests?

Three groups means 3 pairwise tests. Six groups means 15. Each test carries its own 5% false-alarm risk, and the risks pile up:

tibble(groups = c(2, 3, 4, 6, 10)) |>
  mutate(
    pairwise_tests   = choose(groups, 2),
    p_false_alarm    = round(1 - 0.95^pairwise_tests, 2)
  )
# A tibble: 5 × 3
  groups pairwise_tests p_false_alarm
   <dbl>          <dbl>         <dbl>
1      2              1          0.05
2      3              3          0.14
3      4              6          0.26
4      6             15          0.54
5     10             45          0.9

ANOVA’s Answer: One Omnibus Question

By six groups you have a coin-flip’s chance of at least one bogus “significant” difference.

ANOVA asks one omnibus question — are all the group means plausibly equal? — at a single 5% risk. (When we go pairwise afterward, we’ll adjust for this. Hold that thought.)

The Core Idea: Two Kinds of Variance

Imagine Three Classrooms

classrooms <- tibble(
  score     = c(75, 80, 78, 74, 77,    # Class 1
                88, 90, 92, 85, 87,    # Class 2
                70, 65, 68, 72, 66),   # Class 3
  classroom = factor(rep(c("Class 1", "Class 2", "Class 3"), each = 5))
)

class_stats <- classrooms |>
  summarize(class_mean = mean(score), class_var = var(score), .by = classroom)
class_stats
# A tibble: 3 × 3
  classroom class_mean class_var
  <fct>          <dbl>     <dbl>
1 Class 1         76.8       5.7
2 Class 2         88.4       7.3
3 Class 3         68.2       8.2

Two different kinds of “spread” are hiding in this table.

Two Kinds of Variance

Within-group variance: how much scores bounce around inside each classroom.

Between-group variance: how much the classroom averages differ from each other.

mean(class_stats$class_var)   # WITHIN: average spread inside a class
[1] 7.066667
var(class_stats$class_mean)   # BETWEEN: spread of the class means
[1] 102.76

Between (102.8) dwarfs within (7.1) — the class averages are far more spread out than chance bouncing inside classes would suggest. Signal-to-noise ratio ≈ 14.5. These classes look genuinely different.

The Picture

Stanton’s Rain Example (From the Book)

Now flip the situation: three groups where nothing differs — by construction. precip holds annual precipitation for 70 U.S. cities. Draw three random groups of 20 from the same 70 cities:

data("precip")
set.seed(705)   # so we all draw the same "random" groups
group1 <- sample(precip, 20)
group2 <- sample(precip, 20)
group3 <- sample(precip, 20)

c(mean(group1), mean(group2), mean(group3))
[1] 34.100 31.835 31.255

The means differ a little — but any differences here are pure sampling luck. The null hypothesis is true by construction.

Rain: Within vs. Between

mean(c(var(group1), var(group2), var(group3)))    # WITHIN
[1] 132.6697
var(c(mean(group1), mean(group2), mean(group3)))  # BETWEEN
[1] 2.260108

Within ≈ 133, between ≈ 2.3. The classrooms gave us 7.1 vs. 102.8 — completely flipped. Why?

Why So Lopsided?

  • City-to-city rainfall varies a lot (Phoenix vs. Mobile) → big within-group variance
  • But each group’s mean averages 20 cities — and Session 4 taught us means fluctuate far less than raw values (\(SE = \sigma/\sqrt{n}\))
  • With no real group differences, between-group variance is nothing but the tiny sampling noise of three means
  • So the diagnostic: between ≫ within → something real is separating the groups. Between ≪ within → nothing but noise.
  • All we need is a ruler for “how much bigger is big enough” —

The F-Statistic

\[F \;=\; \frac{\text{between-group variance}}{\text{within-group variance}} \;=\; \frac{\text{signal}}{\text{noise}}\]

  • When the null is true, F bounces around low values by luck of the draw
  • If our F lands far in the tail of the F distribution → our data are unlikely under the null — same logic as every test we’ve run
  • The F distribution describes the F values a null world produces. Its shape depends on two df: groups − 1 and N − groups

What F Looks Like When the Null Is True

set.seed(705)
f_null <- tibble(
  design = rep(c("F(2, 57) — our rain design",
                 "F(8, 101) — more groups, bigger N"), each = 10000) |> fct_inorder(),
  f      = c(rf(10000, df1 = 2, df2 = 57), rf(10000, df1 = 8, df2 = 101))
)
cutoffs <- f_null |> summarize(cut = quantile(f, 0.95), .by = design)

ggplot(f_null, aes(f)) +
  geom_histogram(bins = 60, fill = crju_colors["blue"], color = "white") +
  geom_vline(data = cutoffs, aes(xintercept = cut),
             color = crju_colors["garnet"], linewidth = 1.1) +
  facet_wrap(~design, ncol = 1) +
  labs(title = "10,000 F values from a null world, for two designs",
       subtitle = "Garnet line = 95th percentile — F values beyond it are rare when nothing differs",
       x = "F value", y = "Count")

What F Looks Like When the Null Is True

Running the ANOVA

First, We Need a Data Frame

aov() wants the data in the long format we’ve used all semester — one row per observation, one column saying which group it belongs to:

rain <- tibble(
  rainfall = c(group1, group2, group3),
  group    = factor(rep(c("Group 1", "Group 2", "Group 3"), each = 20))
)
rain
# A tibble: 60 × 2
  rainfall group  
     <dbl> <fct>  
1     49.2 Group 1
2     35.1 Group 1
3     31.7 Group 1
4     30.8 Group 1
5     34.4 Group 1
6     17.4 Group 1
# ℹ 54 more rows

aov() Does the Whole Thing

rain_model <- aov(rainfall ~ group, data = rain)
summary(rain_model)
            Df Sum Sq Mean Sq F value Pr(>F)
group        2     90    45.2   0.341  0.713
Residuals   57   7562   132.7

F = 0.34, p = 0.71. That F sits squarely in the fat part of F(2, 57) — nowhere near the 95% cutoff (≈ 3.2). No evidence the groups differ. Correct answer — they’re the same population by construction.

The Table Is Our Two Variances, Dressed Up

  • Mean Sq Residuals = 132.7 — exactly the within-group variance we computed by hand ✓
  • Mean Sq group = 45.2 = 20 × 2.26 — our between-group variance, scaled by the group size
  • Why × 20? A 2-inch gap between means built on 20 cities each is far stronger evidence than the same gap built on 2. aov() bakes the sample size into the signal.
  • F = 45.2 / 132.7 = 0.34. So when your hand-computed ratio and aov()’s F disagree, this scaling is why — same logic, different units.

Let’s Make a Difference Artificially

Shift Group 3 down 15 inches — now there is a real difference, and we know exactly where it lives:

rain_shifted <- rain |>
  mutate(rainfall = if_else(group == "Group 3", rainfall - 15, rainfall))

rain_shifted |> summarize(mean_rain = mean(rainfall), .by = group)
# A tibble: 3 × 2
  group   mean_rain
  <fct>       <dbl>
1 Group 1      34.1
2 Group 2      31.8
3 Group 3      16.3

Original vs. Shifted, Seen

Redo the ANOVA

shifted_model <- aov(rainfall ~ group, data = rain_shifted)
summary(shifted_model)
            Df Sum Sq Mean Sq F value     Pr(>F)    
group        2   3775  1887.7   14.23 0.00000972 ***
Residuals   57   7562   132.7                       
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

The within-group noise didn’t move (132.7 — shifting a whole group doesn’t change the spread inside it). The between-group signal exploded. F = 14.2, p ≈ 0.00001 — deep in the tail.

A Significant F Only Says “Something Differs”

Which pairs? Tukey’s HSD: all pairwise comparisons, with the family-wise 5% false-alarm rate restored — the fix for the t-test pile-up problem from the top of class:

TukeyHSD(shifted_model)
  Tukey multiple comparisons of means
    95% family-wise confidence level

Fit: aov(formula = rainfall ~ group, data = rain_shifted)

$group
                   diff      lwr       upr     p adj
Group 2-Group 1  -2.265 -11.0301  6.500103 0.8087836
Group 3-Group 1 -17.845 -26.6101 -9.079897 0.0000246
Group 3-Group 2 -15.580 -24.3451 -6.814897 0.0002129

Reading the Tukey Output

  • Group 3 differs from both others — intervals exclude 0, adjusted p-values tiny. Exactly where we put the difference.
  • Group 1 vs. Group 2: interval spans 0, p = 0.81 — no evidence, as designed
  • The omnibus F said “something’s there”; Tukey pointed at what, without inflating the false-alarm rate

The Bayesian Version

Two New Packages

  • brms — Bayesian Regression Models using Stan: writes the model, compiles it, samples the posterior
  • emmeans — estimated marginal means: takes any fitted model and returns group means and group differences
install.packages(c("emmeans", "brms"))

brms compiles models with your computer’s C++ toolchain. Install before the lab, and expect the first model of each session to pause ~a minute at “Compiling Stan program…” — that’s normal, not a crash.

Same Formula, Bayesian Machinery

bayes_rain <- brm(rainfall ~ group, data = rain,
                  chains = 2, iter = 2000, seed = 705, refresh = 0)
  • Identical formula syntax to aov() — this pattern carries through the rest of the course
  • Default priors: flat on the group coefficients — the data do the talking
  • chains = 2, iter = 2000: two independent MCMC runs, 2,000 draws each → a full posterior distribution for every group mean
  • refresh = 0 just silences the sampling progress log

Posterior Group Means

rain_post <- emmeans(bayes_rain, ~ group)
rain_post
 group   emmean lower.HPD upper.HPD
 Group 1   34.2      28.8      38.9
 Group 2   32.0      27.1      37.1
 Group 3   31.4      26.5      36.5

Point estimate displayed: median 
HPD interval probability: 0.95

One row per group: the posterior median and a 95% HPD interval — the range holding the most credible values for that group’s mean, given the data.

Posterior Means, Seen

plot(rain_post) +
  geom_vline(xintercept = mean(rain$rainfall),
             linetype = 2, color = crju_colors["garnet"]) +
  labs(x = "Posterior mean rainfall (inches)", y = NULL)

All three intervals swallow the grand mean (dashed line). No group separates from the pack.

What We Really Care About Are Differences

pairs(rain_post)
 contrast          estimate lower.HPD upper.HPD
 Group 1 - Group 2    2.233     -5.05      9.20
 Group 1 - Group 3    2.733     -4.34      9.93
 Group 2 - Group 3    0.506     -7.00      7.57

Point estimate displayed: median 
HPD interval probability: 0.95
  • Every 95% HPD interval for a pairwise difference crosses 0
  • Bayesian reading: zero — “no difference” — remains a credible value for every contrast. No credible difference between any pair.
  • Same verdict as F = 0.34, p = 0.71. Two traditions, one conclusion.

Differences, Seen

plot(pairs(rain_post)) +
  geom_vline(xintercept = 0, linetype = 2, color = crju_colors["garnet"])

Zero sits comfortably inside every interval. When a difference is real, its interval abandons 0 — watch what real data do next.

Real Data: Does the Clock Differ by Crime Type?

The Question

In Session 5 we found violent crimes average slightly later in the day than property crimes — two groups. But our Chicago data sort every incident into three categories. ANOVA takes all three in one shot:

crimes |> summarize(mean_hour = mean(hour), sd_hour = sd(hour),
                    n = n(), .by = crime_category)
# A tibble: 3 × 4
  crime_category mean_hour sd_hour     n
  <chr>              <dbl>   <dbl> <int>
1 Violent             12.8    6.87  9148
2 Other               12.1    6.95 10481
3 Property            12.5    6.63 10371

Violent runs latest (12.8), Other earliest (12.1). Gaps of fractions of an hour, with SDs near 7. Real structure, or noise? And remember: n = 30,000 — big samples detect tiny things.

Look First

Frequentist: aov()

chicago_model <- aov(hour ~ crime_category, data = crimes)
summary(chicago_model)
                  Df  Sum Sq Mean Sq F value          Pr(>F)    
crime_category     2    2351  1175.3    25.3 0.0000000000105 ***
Residuals      29997 1393374    46.5                            
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

F(2, 29997) = 25.3, p ≈ 10⁻¹¹. Something differs, emphatically. But that’s all the omnibus F will ever tell us — which pairs, and by how much?

Which Pairs? Tukey

TukeyHSD(chicago_model)
  Tukey multiple comparisons of means
    95% family-wise confidence level

Fit: aov(formula = hour ~ crime_category, data = crimes)

$crime_category
                      diff        lwr       upr     p adj
Property-Other   0.4285629 0.20732516 0.6498006 0.0000168
Violent-Other    0.6812419 0.45269164 0.9097921 0.0000000
Violent-Property 0.2526790 0.02356458 0.4817934 0.0263613

All three intervals exclude 0 — every category differs from every other. Now look at the sizes: 0.25 to 0.68 hours. That’s 15 to 41 minutes.

Bayesian: Same Workflow, Real Data

bayes_chicago <- brm(hour ~ crime_category, data = crimes,
                     chains = 2, iter = 2000, seed = 705, refresh = 0)

The exact pattern from the rain example — brm(), then emmeans(), then pairs(). Nothing new to learn; only the data changed.

Bayesian Differences

chicago_post <- emmeans(bayes_chicago, ~ crime_category)
pairs(chicago_post)
 contrast           estimate lower.HPD upper.HPD
 Other - Property     -0.427    -0.610    -0.248
 Other - Violent      -0.681    -0.858    -0.487
 Property - Violent   -0.256    -0.454    -0.065

Point estimate displayed: median 
HPD interval probability: 0.95

Every HPD interval excludes 0 — all three differences are credible. (Watch the signs: emmeans orders groups alphabetically, so these are Other − Property, Other − Violent, Property − Violent — the mirror image of Tukey’s table. Same gaps.)

Detectable ≠ Dramatic (Reprise)

  • Both traditions agree: mean incident hour genuinely differs across all three categories
  • But the biggest gap is 41 minutes and the smallest is 15 minutes — on a 24-hour clock, with SDs near 7 hours
  • 30,000 incidents give us the power to detect differences this small. Detecting them is not the same as their mattering.
  • Your job as the analyst: report direction and size, every time. “Significant” without magnitude is malpractice — Session 6’s lesson, now with three groups.

How to Report It

Frequentist: “Mean incident hour differed across crime categories, F(2, 29997) = 25.3, p < .001. Tukey’s HSD: violent crimes averaged 0.25 hours (≈ 15 minutes) later than property crimes, 95% CI [0.02, 0.48], with similarly small gaps for the other pairs.”

Bayesian: “The posterior difference in mean hour (Violent − Property) was 0.26 hours, 95% HPD [0.06, 0.45], excluding zero — a credible but small difference.”

Both sentences state the difference, the uncertainty, and the magnitude.
