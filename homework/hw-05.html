Homework 5 · Confidence Intervals in Practice

CRJU 705 · due by 11:59 pm Sunday ahead of Session 6

Instructions: complete the following exercises in a single .R script file. Include comments explaining your code and answers to any interpretive questions. Submit your .R file via Canvas for credit.

This homework uses the Alaska traffic-crash data from Lab 4 — 20,000 real-world-style crash incidents. Our research question: do crashes involving an intoxicated driver injure more people than crashes that don’t? Every step below is one you ran in Lab 5, pointed at a new question.

Start your script with:

library(tidyverse)
crashes <- read_csv("https://smourtgos.github.io/crju705/data/crash-ak.csv")

Part 1: Import and Name the Groups

  1. Run glimpse(crashes). The column intox_any is 1 when the driver was intoxicated and 0 when not.

  2. Copy this line into your script and run it. It labels each crash in words, so every later result reads “Intoxicated” and “Sober” instead of 1 and 0:

    crashes <- crashes |> mutate(intox = if_else(intox_any == 1, "Intoxicated", "Sober"))

  3. Count the two groups with crashes |> count(intox). In a comment: how many crashes are in each group? You will type these two numbers into prop.test() in Part 5.

Part 2: Point Estimates and Spread

  1. Get the mean and standard deviation of injuries for each group in one table:

    crashes |>
  summarize(mean_injuries = mean(injuries), sd_injuries = sd(injuries), n = n(), .by = intox) |>
  arrange(intox)

  2. In a comment: write down each mean. Which group has the higher average injury count? Remember what these numbers are — point estimates, not the final word.

  3. In a comment: compare the two standard deviations. Which group’s injury counts vary more?

Part 3: Visualize

  1. Make a boxplot of injuries for the two groups:

    ggplot(crashes, aes(x = intox, y = injuries)) +
  geom_boxplot()

  2. In a comment: interpret the plot. Injury counts are small whole numbers, so the boxes look blocky — can you see a difference between the groups, or do you need inference to settle it?

Part 4: The Interval, with t.test()

  1. Run the two-sample t-test, exactly as in Lab 5:

    t.test(injuries ~ intox, data = crashes)

  2. In a comment: copy down the 95% confidence interval. Does it include 0? Then do the direction check from lab: the output lists Intoxicated first, so the interval is Intoxicated minus Sober. Confirm that its sign agrees with the two group means at the bottom of the output.

  3. In a comment: say what the interval means in words, the way we did in class: about how many more (or fewer) injuries per crash, and does the data settle the direction?

Part 5: A Proportion, for Practice

  1. Compute a 95% confidence interval for the proportion of all crashes that involve an intoxicated driver. Type the two numbers from your Part 1 count into prop.test(): how many intoxicated, out of how many crashes.

  2. In a comment: report the interval in one defensible sentence — one that would survive the “Saying It Out Loud” slide from class.

Wrap-Up Questions (answer in comments)

  1. How does the confidence interval help us make an inference about the population of Alaska crashes, when we only ever see a sample?
  2. What would happen to the width of the CI if we doubled the sample size? Why?
  3. How does this example compare to John Snow’s inference about the cholera pumps?

R4DS Exercises (required)

From your R4DS reading for Session 6 — Ch. 16, Factors. No new packages: the gss_cat survey data ships with the tidyverse. All four exercises are about one idea from today: the order of the groups is a choice you make, not something R knows.

Work these in the same .R script, under a # ---- R4DS ---- header.

  • 16.3.1 #2 — what is the most common relig in this survey? The most common partyid? (count() and arrange() will do it.)

  • 16.3.1 #1 — make the default bar chart of rincome. What makes it hard to read? How could you improve it? (Hint: the two problems are the overlapping labels and the order of the levels. aes(y = rincome) fixes the first one.)

  • 16.4.1 #2 — for each of the six factor columns in gss_cat (marital, race, rincome, partyid, relig, denom), is the order of the levels arbitrary or principled? One comment line each. count() the column, or run levels() on it, to see the order.

  • 16.5.1 #2 — collapse rincome into a small set of categories. Start from this, which runs as-is:

    gss_cat |>
  mutate(rincome2 = fct_collapse(rincome,
    "Unknown"       = c("No answer", "Don't know", "Refused", "Not applicable"),
    "Under $10,000" = c("Lt $1000", "$1000 to 2999", "$3000 to 3999", "$4000 to 4999",
                        "$5000 to 5999", "$6000 to 6999", "$7000 to 7999", "$8000 to 9999")
  )) |>
  count(rincome2)

    Then add the four remaining bands ("$10000 - 14999", "$15000 - 19999", "$20000 - 24999", "$25000 or more") into one or two groups of your choosing, and run count() again.

Chapter 16 has more exercises than these. Skip them; these four are the ones worth your time.
